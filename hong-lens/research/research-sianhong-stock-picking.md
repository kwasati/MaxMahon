## 1. Summary

- **เซียนฮง = Hybrid Value Investor** ไม่ใช่ pure value แบบ ดร.นิเวศน์ + ไม่ใช่ pure long-term hold แบบ Buffett — ใช้พื้นฐาน 99% แต่ยอม cut loss และ rotate
- **เกณฑ์ที่ verify ตรงจากแกได้** = D/E ≤ 1x, Entry 30:30:30:10, Cut loss ที่ ~8%, ROE สูง + Cash flow ≈ Net profit, Forward PE ต่ำกว่าตลาด
- **ผู้บริหารคือตัวแปรอันดับ 1** — ซื่อสัตย์ + เก่ง + มีไฟ ครบ 3 ข้อ ก่อนดูตัวเลข
- **Case study ของจริง** = PTL (6x ใน 6 เดือน, 2010) / KTC (9.6x ใน 7 ปี, 2013-2020) / OR (big bet 7.7 พันล้าน, exit 1 ปี) / DITTO (ติดแหง็ก, ตัดขาย 2025)
- **หนังสือมี 2 เล่ม** เท่านั้น — "รวยได้ด้วยหุ้น" + "รวยหุ้นได้จริง" (ฉบับปรับปรุง 2020) ไม่มีเล่มใหม่หลัง 2020

**Critical correction จากที่เคยพูดในแชท:**
- "Super Stock" เป็น brand ของ ดร.นิเวศน์ มากกว่า — เซียนฮงไม่ได้ใช้คำนี้เป็นหลัก
- เซียนฮงไม่เคยถือ AOT / KCE / COM7 / DELTA / BH / BEAUTY ใน public record — ของจริงคือ PTL / KTC / OR / DITTO / CPF / VNG / CPALL / JMT / TISCO / IVL
- "หุ้นไม่ใช่ภรรยา" — ไม่พบ source ยืนยันว่าเซียนฮงพูด
- "PEG < 1" — เซียนฮงพูดถึง PEG เชิง concept แต่ไม่ระบุ threshold ตัวเลข
- "ถือ 1-3 ปี" — จากของจริง KTC ถือ 7 ปี / PTL 6 เดือน / OR 1 ปี → range กว้างกว่าที่กูเคยพูด

## 2. Findings

### 2.1 Background ของเซียนฮง

- ชื่อจริง: **สถาพร งามเรืองพงศ์** ฉายา "เซียนฮง" (ฮง = "เพื่อนที่ดีและมีลาภ" ในภาษาจีน)
- ครอบครัวค้าเสื้อยืดย่านพระราม 2 ไม่ได้รวยมาก
- เริ่มลงทุน 2547 (อายุ 19 ปี ปี 1 ม.กรุงเทพ) ด้วย **100,000 บาท**
- 2552-2553 พอร์ตขยาย 40-50 เท่า (CPF, VNG, PTL)
- 2562 พอร์ตแตะ ~6,000 ล้านบาท (ผู้ถือหุ้นใหญ่อันดับ 4 ของ KTC)
- Peak สูงสุดเคยแตะระดับหมื่นล้าน
- 2566 มูลค่าลงเหลือ ~2,789 ล้านบาท (พอร์ตติดลบหลัง OR + DITTO + COVID)
- 2569 พอร์ต ~1.83 พันล้านบาท (TISCO ใหญ่สุด)

> **Style note:** เซียนฮงเงียบ ไม่ค่อยให้สัมภาษณ์ — เพิ่งออกสาธารณะหลัง 2562 ข้อมูลส่วนใหญ่ดูจาก SET filing โดยตรง ไม่ใช่จาก interview

### 2.2 ปรัชญาหลัก — 3 ข้อใหญ่

**ข้อ 1 — ซื้อธุรกิจ ไม่ซื้อกระดาษ**
มองหุ้นเป็นการถือครองส่วนหนึ่งของธุรกิจจริง ไม่ใช่ตั๋วพนัน ตลาดหุ้นคือ "สถานที่จับจองธุรกิจ"

**ข้อ 2 — ผู้บริหาร คือตัวแปรที่ 1**
เกณฑ์หลักคือผู้บริหารต้องมีครบ 3 ข้อ: **ซื่อสัตย์ + เก่ง + มีไฟ**
- วัด "ซื่อสัตย์": ดูประวัติถูก กลต./ตลท.ปรับ + ค่าใช้จ่ายผิดปกติเทียบ peer
- วัด "เก่ง": ROE สูง = บริหาร capital ได้ดี
- วัด "มีไฟ": ฟัง investor presentation + ความสามารถสร้าง value add

**ข้อ 3 — ซื้อก่อนคนอื่นรู้ ขายเมื่อทุกคนรู้แล้ว**
ซื้อ "กบก่อนที่มันจะกลายเป็นเจ้าชาย" — Forward P/E ต่ำกว่า 15x คือ zone ที่ชอบ

**Style:** เริ่มต้นพื้นฐาน 70% + เทคนิค 30% → พอร์ตใหญ่ขึ้นเปลี่ยนเป็น พื้นฐาน ~99% (ข้อจำกัดสภาพคล่อง)

---

### 2.3 เกณฑ์คัดหุ้นเชิงตัวเลข — 5 Criteria หลัก

จาก Kaohoon (cross-confirm efinancethai):

| # | ตัวชี้วัด | เกณฑ์ที่ระบุ |
|---|-----------|-------------|
| 1 | หนี้สินกับสถาบันการเงิน | **D/E ≤ 1x** (ค้าปลีกอาจเกินได้ถ้าเป็นเจ้าหนี้การค้า) |
| 2 | เงินสดในมือ | มีเพียงพอจ่ายหนี้ + ปันผล |
| 3 | Gross Margin + Net Margin | ดูแนวโน้ม สะท้อนคุณภาพผู้บริหาร เทียบกับ peer |
| 4 | กระแสเงินสดเทียบกำไรสุทธิ | **Cash flow ≈ Net profit** (ถ้าต่างมาก = สัญญาณตบตา) |
| 5 | ROE | ดูเชิง relative กับอุตสาหกรรม (ไม่มี absolute threshold) |

**เกณฑ์เพิ่มเติมจากหนังสือ (secondary source — ระวัง):**
- **กำไรสุทธิทำ all-time high ใหม่** + รักษาระดับได้ต่อเนื่อง
- **กำไรโต ~26%/ปี ต่อเนื่อง 3 ปี** (เพิ่มเป็น 2 เท่าใน 3 ปี) — *ตัวเลขจาก FinSpace summary ไม่ใช่ verbatim*
- **Forward P/E ≤ 15x** สำหรับหุ้นเติบโตที่ยังไม่ดัง — *จาก FinSpace summary*
- **Dividend yield 4-7%/ปี** บอกว่ากำไรจริง — *จาก FinSpace summary*

**PEG:**
- เซียนฮงพูดถึง PEG เชิง concept ว่า "ดู PEG ต่ำจะดีกว่า" แต่**ไม่ระบุ threshold ชัด** (ไม่ใช่ "< 1" หรือ "< 0.5")
- จากบริบทหนังสือ: กำไรโตต้องสูงกว่า Forward PE อย่างน้อย 1.5 เท่า

**Market cap:**
- ไม่มี rule ชัด — ของจริงถือทั้ง small cap < 1B (BVG, MICRO, SEI) และ large cap (OR เคย 7.7 พันล้านบาท)
- พฤติกรรม: ชอบ mid-to-small cap ที่ยังไม่ถูก market สนใจ

### 2.4 Entry — Formula 30:30:30:10

- ซื้อครั้งแรก **30%** ของเงินที่ตั้งใจลงทุนในตัวนั้น
- ซื้อเพิ่ม **30%** เมื่อราคาขึ้น 7-8%
- ซื้อเพิ่ม **30%** ถ้ายังขึ้นต่อ
- เก็บ **10%** ไว้สำรอง
- **Cut loss ทันที** ถ้าราคาลง 8% จากที่ซื้อ (บางแหล่งระบุ 5-8%)

> Verified: ปรากฏใน thaivalueinvest blog 2012 + Finnomena cross-confirm

---

### 2.5 Exit — สัญญาณขาย

- **Cut loss -8%** หลังซื้องวดแรก (vinyl rule)
- **Let Profit Run** — ไม่ขายเพียงเพราะราคาขึ้น
- **ขายเมื่อ thesis พัง** = "ขายเมื่อยอมรับว่าคิดผิด"
- **Fundamental เปลี่ยน** → ออก
- ตัวอย่างจริง: OR (มี.ค. 2565 ขายทั้งพอร์ต) / BE8 (2566 ตัดบางส่วน) / DITTO (2568 ตัดเกือบหมด)

---

### 2.6 Risk Management

- **Margin: ใช้ได้แต่ต้องผ่านตลาด 10+ ปี + วัฏจักรหลายรอบ** ก่อน
- เคยใช้ margin ช่วงต้น (PTL trade 60% margin) → ได้ผลในตลาดขาขึ้น แต่ปี 2554-55 ขาดทุนหนักจาก warrant อสังหา + telco 3G → เปลี่ยน style เลิก margin หลังจากนั้น
- **Cash position:** ไม่มี rule ชัด — บอกแค่ "ถ้า SET ไม่ถึง 1,100 จุด จะยังไม่ซื้อเพิ่ม" (context 2023-2024)
- **ไม่มี hedging** ที่พูดถึงเป็นระบบ

---

### 2.7 สิ่งที่แก "ไม่ซื้อ"

- **ผู้บริหารถูก กลต./ตลท. เรียกปรับ** = filter แรกก่อนดู financials
- **ผู้บริหารพูดเกินจริง / เอาเปรียบสังคม**
- **ค่าใช้จ่ายสูงกว่า peer ผิดปกติ** = สัญญาณตบตา
- **ไม่มี sector ที่แกประกาศห้ามตัวเอง** — แต่จากพอร์ตจริงเลี่ยง commodity-linked + heavy industry

## 6. ความต่างจาก ดร.นิเวศน์ และ Buffett

| มิติ | เซียนฮง | ดร.นิเวศน์ | Buffett |
|------|---------|------------|---------|
| Style | Hybrid (Value + Growth) | Pure Value (เน้นปันผล) | Value + Quality |
| Cut loss | **ใช่ -8%** | ไม่ | ไม่ |
| Hold time | 6 เดือน - 7 ปี (variable) | 10-20+ ปี | "Forever" |
| ปันผล | นิยมแต่ไม่ใช่หลัก | **เสาหลัก** | ไม่สนใจ |
| Concentration | สูง (PTL 100% + margin) | ต่ำ (10-20 ตัว) | สูง (5-10 ตัวหลัก) |
| Margin | เคยใช้ → เลิก | ไม่ใช้ | Float ประกัน |
| Catalyst | ผู้บริหาร + กำไร new high | ปันผลเพิ่มทุกปี | Moat |
| Tech | 30% ตอนต้น → 0% ตอนพอร์ตใหญ่ | 0% | 0% |

**Note:** ไม่พบ quote ตรงจากเซียนฮงเปรียบเทียบกับ ดร.นิเวศน์ — ความต่างนี้ inference จาก style observation

3. **กำไร new high + Cash flow ≈ Net profit + D/E ≤ 1x** = filter พื้นฐาน
4. **เลี่ยง commodity / heavy industry** — ไม่ใช่ rule แต่เป็นพฤติกรรมจริงของแก
5. **ระวัง concentration** — แม้แกใส่หนัก (PTL 100%) แต่ภายหลังก็เจ๊งจาก concentration เดียวกัน (warrant อสังหา 2554)
