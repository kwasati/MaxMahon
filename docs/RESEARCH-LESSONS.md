## 1. เกณฑ์คัดหุ้นแบบไบนารี 5-5-5-5

**หลักการ:** คัดหุ้นด้วย 5 เช็คแบบ binary (ผ่าน/ไม่ผ่าน) แทนสูตร weighted score — คะแนนเต็ม 5:
1. เงินปันผลต่อหุ้น (DPS) ขึ้นทุกปี 3 ปีติด (เช่น 2022→2023→2024) แบบ strict pairwise (ต้องขึ้นทุกคู่ปี ไม่ใช่แค่ปีสุดท้ายมากกว่าปีแรก)
2. รายได้ + กำไร ขึ้นทุกปี 3 ปีติด แบบ strict pairwise เดียวกัน
3. กระแสเงินสดจากการดำเนินงาน (OCF) บวกทุกปี 3 ปี
4. กระแสเงินสดอิสระ (FCF) บวกทุกปี 3 ปี
5. อัตราส่วนกระแสเงินสดต่อกำไร (OCF/NI) ปีล่าสุด ≥ 1.0 — กำไรกลายเป็นเงินสดจริง ไม่ใช่แค่ตัวเลขบัญชี

Tier S = ผ่านครบ 5/5, Tier A = ผ่าน 4/5 ไล่ลงไป

หมายเหตุ: 5 เช็คข้างบนเป็นเกณฑ์ตรวจมือของ manual ranking ไม่ใช่สูตร 5-5-5-5 ของนิเวศน์ (สูตรจริง = ยีลด์วันนี้ ≥5% / อีก 5 ปียังไม่น้อยกว่า 5% / ≥5 หุ้น 5 อุตสาหกรรม / ตั้งเป้าถือ 5 ปี — S1 ใน `docs/niwes-principles.md`)

**ทำไม / เจอจาก:** ทำ manual ranking บนหุ้น 56 ตัวที่ผ่าน screener 5-5-5-5 ของ algo มาแล้ว (yield ≥5%) — ตั้งใจ "ตรวจมือ ไม่พึ่ง score formula ของ algo — เน้น strict YoY check + cash quality" เพราะ weighted score เดิมทำให้ตัวเลขสูงด้านหนึ่งกลบความอ่อนด้านอื่นได้ ผลจริง: HTC + BBL ผ่านครบ 5/5 เป็น Tier S

**ใช้ตอนไหน:** ตอนต้องคัดหุ้นแบบเข้มงวดจริง ไม่ยอมให้จุดแข็งด้านเดียว (เช่น yield สูงมาก) กลบจุดอ่อนด้านอื่น (เช่น กำไรไม่ขึ้นทุกปี) — binary บังคับให้ทุกด้านต้องผ่านจริงถึงจะได้คะแนน

## 2. แผนที่เกณฑ์ 13 ข้อ — แยกว่าข้อไหนเครื่องคำนวณได้ ข้อไหนต้องคนตัดสิน

**หลักการ:** เกณฑ์ ดร.นิเวศน์ ทั้งหมด 13 ข้อ แบ่งเป็น 2 กลุ่มชัดเจนตามธรรมชาติของข้อมูล:
- **กลุ่มเลขได้ (Quant, algo คำนวณได้):** yield ≥5% ตอนนี้ / yield ≥5% อีก 5 ปี (ต้อง project) / PE 7-8 / PBV <1.0 / จ่ายปันผลจาก operating profit (ดู OCF/FCF/Cash 3 ปี) / รายได้-กำไร-ปันผล เพิ่มทุกปี (strict YoY) / hidden value (sum-of-parts > mcap) / ROE 10 ปี + ไม่เคยขาดทุน / กระจาย 5+ หุ้น 5+ sector
- **กลุ่มต้องคนคิด (Qualitative):** ธุรกิจอยู่กับเรา 3+ ปี (structural change ของ sector) / moat หรือ mid-tier ที่ยังโตได้ (เทียบคู่แข่งใน sector) / daily-use + ไม่ sexy (พฤติกรรมผู้บริโภค) / geographic 30/30/30/Cash (portfolio strategy)

ตอนทำ manual ranking 2026-05-19 คลุมได้แค่ครึ่งเดียวของ 13 ข้อ (5 ข้อจากฝั่ง quant) ที่เหลือยังไม่ได้ทำ

**ทำไม / เจอจาก:** ต้องการรู้ชัดว่าระบบคัดที่มีอยู่ "คลุม" เกณฑ์ Niwes ไปถึงไหนแล้ว กันเข้าใจผิดว่า pass filter = ครบเกณฑ์ Niwes ทั้งหมด

**ใช้ตอนไหน:** ก่อนออกแบบ/ขยายด่านคัดหรือใบข้อเท็จจริงใหม่ ต้องเช็คก่อนว่าเกณฑ์ไหน "เอาเข้าเครื่องได้" (มีสูตร/ข้อมูลชัด) เกณฑ์ไหน "ต้องมีคนอ่าน/ตัดสิน" (เช่น moat, พฤติกรรมผู้บริโภค) — กันเสียเวลาพยายาม automate สิ่งที่ automate ไม่ได้จริง

**อ้างอิง:** `_archive/2026-10/research/niwes-criteria-coverage-map.md` ทั้งไฟล์ (เก็บแล้ว · นับ PE ≤15 / PBV <1.5 ว่า "คลุมเกณฑ์" ทั้งที่เป็นเลขที่เราตั้งเอง ไม่ใช่เกณฑ์ของนิเวศน์ — ดูท่อน 2.1 ใน `docs/niwes-principles.md`)

## 3. หลักการตัดสินใจสายลงทุนระยะยาว

**หลักการ:** แนวทาง ดร.นิเวศน์ (Niwes Way) คือ "จิตวิญญาณ" (spirit) + การกระจายพอร์ต (diversification) — ไม่ใช่ตารางจัดอันดับ (ranking table) ที่ตายตัว หุ้น tier ต่ำกว่าก็เป็น position สำคัญของพอร์ตได้ ถ้าเข้ากับ spirit + ช่วยกระจายความเสี่ยง ("กันตาย" เป็น concern หลัก) เครื่องมือ/สำนักอื่น (เช่น Jitta score) ให้ถือเป็น **มุมมองเสริม (secondary perspective)** เท่านั้น ห้าม over-weight จนหลุดออกจากแนว Niwes Way และเมื่อผลการตัดสินใจ/โหวตแกว่งไปมาหลายรอบในการคุยครั้งเดียว ให้กลับไปที่ "จุดที่นิ่ง" (stable point) แทนไล่ตามรอบล่าสุดที่เพิ่งแกว่งไป

**ทำไม / เจอจาก:** ใน session 2026-05-21 ความเห็นแกว่ง (vibrate) 6 ครั้งระหว่างคุย ก่อนจะกลับมาสรุปที่จุดนิ่ง = BBL + TCAP

**ใช้ตอนไหน:** ตอนตัดสินใจเลือก/ตัดหุ้นเข้าพอร์ตแล้วเกิดเปลี่ยนใจไปมาหลายรอบในบทสนทนาเดียว — ให้หยุดแล้วย้อนกลับไปจุดที่เคยนิ่งแทนการไล่ตามความเห็นล่าสุด

**อ้างอิง:** `projects/4-MaxMahon/research/_session_summary_2026-05-21.md` บรรทัด 177-191

## 4. โครงวิเคราะห์หุ้นรายตัว 5 แกน

**หลักการ:** วิเคราะห์หุ้นแต่ละตัวแยกเป็น 5 แกน ให้คะแนน 0-3 ต่อแกน:
1. **Financial** — ตัวเลขการเงิน verified (5-binary, DPS/OCF/ROE trend)
2. **Industry** — แนวโน้ม sector ระยะยาว (secular tailwind/headwind, disruption risk)
3. **Moat** — ความได้เปรียบเชิงโครงสร้างที่ยั่งยืน (network effect, license, land bank, franchise)
4. **Management + Capital Allocation** — วินัยจ่ายปันผล/ใช้เงินทุน (DPS growth streak, payout policy, re-invest decision)
5. **Ownership** — โครงสร้างผู้ถือหุ้น/ใครคุม (family/state/institutional, alignment กับผู้ถือหุ้นรายย่อย)

จบแต่ละตัวด้วย **บทบาทในพอร์ต** (anchor / satellite / avoid) + entry timing + **น้ำหนักที่แนะนำ** (% ของพอร์ต pillar 1)

**ทำไม / เจอจาก:** ใช้จริงกับ 4 ตัว (BBL/HTC/AMATA/PTTEP) — โครงนี้แยกให้เห็นชัดว่าหุ้นที่แกนหนึ่งดีมาก ไม่ได้แปลว่าแกนอื่นดีตาม เช่น HTC moat ได้ 3/3 (Coca-Cola franchise ผูกขาดภาคใต้) แต่ management ได้แค่ 1/3 เพราะ DPS ตกต่อเนื่อง 4 ปี — ถ้าให้คะแนนรวมมิติเดียวจะกลบจุดอ่อนนี้ไปเลย ผลสรุป: AMATA (13/15) กับ BBL (12/15) เป็น anchor, HTC (10/15) เป็น satellite, PTTEP (8/15) avoid สำหรับ DCA 10-20 ปี

**ใช้ตอนไหน:** เขียนรายงานวิเคราะห์หุ้นตัวเดียวแบบลึกก่อนตัดสินใจตั้งเป็น anchor position ในพอร์ต — ใช้เมื่อผ่าน filter เบื้องต้นแล้วและต้องการดูรอบด้านก่อนตัดสินใจน้ำหนัก

## 5. อย่าตั้งน้ำหนักคะแนนบนที่มาที่เปิดตรวจไม่ได้ — คะแนน 0–100 ถูกถอดออกแล้ว

**หลักการ:** สเปกคะแนน 0–100 เดิม (ปันผล 35 / cash flow 25 / moat 25 / ถือยาว 15 + ป้ายหักคะแนน) อ้างน้ำหนักและโทษว่ามาจาก "Niwes ch3–ch7" แต่ไม่มีไฟล์ต้นทางให้เปิดตรวจ (`C:/WORKSPACE/reMarkable/scripts/tmp/niwes-book/` ไม่มีในเครื่อง · คำยกไม่อยู่ในแหล่ง 57 รายการของ `docs/niwes/00-sources.md`) — น้ำหนักทุกตัวจึงเป็นเลขที่เราตั้งเอง ไม่ใช่คำของนิเวศน์ · ระบบถอดคะแนนออกแล้ว (commit ebb5390) เหลือด่านคัด + ใบข้อเท็จจริง + ธง ส่วนคำตัดสินเป็นของ Art กับหัวหลัง deep dive

**ทำไม / เจอจาก:** สเปกเดิมสรุปว่า "ทำงานตรงปรัชญา" เพราะ PTT/SCC/CPALL ได้ 0 ตามกฎ invariant — แต่ CPALL คือหุ้นที่นิเวศน์ถือ 17 ปี การได้ 0 จึงเป็นสัญญาณว่าสูตรผิด ไม่ใช่ context เปลี่ยน · ข้อสรุป "drift จาก context ไม่ใช่ bug ของสเปก" ยืนบนที่มาที่ยืนยันไม่ได้ · รายการจุดขัดอยู่ที่ `docs/review-2026-10/niwes-vs-system.md` (E1–E5) หลังแยกไฟล์ (ไฟล์หลักคือ `docs/niwes-principles.md`)

**ใช้ตอนไหน:** ก่อนเขียนสเปกที่อ้างคำของใคร — ต้องมีแหล่งที่เปิดได้ และติดป้ายว่าพูดจริง / ผู้อื่นตีความ / เราตั้งเอง (ป้ายอยู่ใน `docs/niwes-principles.md`) · ผลที่ออกมาขัดกับกรณีที่เจ้าของปรัชญาทำจริง (เช่น CPALL) ให้สงสัยสูตรก่อนสงสัยตลาด · เมื่อรวมหลายด้านเป็นเลขเดียว จุดแข็งด้านหนึ่งกลบจุดอ่อนอีกด้านได้ — ระบบปัจจุบันจึงไม่รวมคะแนน
